1. Qué se agregó y cómo funciona

Se suma la clase 06.4.1 Prepagas y obras sociales, calculada con los cuadros tarifarios que las entidades declaran cada mes en el sitio de la SSSalud. Los precios cambian una vez por mes, por eso esta clase se mide por mes y no por semana.

TemaCómo quedó
Tilde en la app«Incluir prepagas (se mide por mes)», apagado por defecto. Apagado: la semanal de Alimentos y todo lo demás da igual que antes. Prendido: se calcula 06.4.1 y entra en el mensual.
RegionesSe calcula en las 6 regiones INDEC y se combina con los ponderadores regionales de INDEC para el dato nacional.
HistoriaSolo desde julio 2026 (el relevamiento no existía antes). Se cambia con --desde.
ActualizaciónVa incluida en actualizar: baja meses nuevos y revisa los dos últimos por si cambiaron.
Importante: si las dos ventanas que comparás caen en el mismo mes, la variación de prepagas es 0% (no hubo cambio de cuota). Si cruzan de mes, entra el salto de cuota, ponderado por días.

2. Instalar la versión nueva sin perder datos

  1. Cerrá cualquier ventana donde esté corriendo la app o un script.
  2. Descomprimí el ZIP nuevo en una carpeta temporal (por ejemplo el Escritorio).
  3. Copiá el contenido de la carpeta nueva relevamiento-precios sobre la tuya, eligiendo «reemplazar». No borres tu carpeta: ahí están la base de datos (.db), historico y datos_sepa, que el ZIP no trae.
  4. Confirmá que sigue existiendo historico\ con los .csv.gz.
cd C:\Users\tobia\OneDrive\Desktop\JPM\IPC\relevamiento-precios
dir historico | more
dir externos\prepagas

3. Verificar (tests y conexión al sitio)

  1. Correr los tests: deben dar Total: 309 OK: 309 Fallidos: 0.
  2. Probar que tu PC llega al sitio: --listar debe mostrar los períodos (202507 a 202611).
python -m tests._runner
python -m scripts.descargar_prepagas --listar
El descargador se probó contra una API simulada; los datos reales se leyeron desde un navegador. Si --listar falla con error de acceso, andá directo al punto 8 (Plan B).

4. Primera descarga (julio 2026 en adelante)

Cada mes tiene ~12 mil filas y se baja entidad por entidad (puede tardar varios minutos por mes). Si un mes queda incompleto no se guarda: nunca queda un archivo a medias.

python -m scripts.descargar_prepagas --faltantes

Equivale a bajar todo lo que falta desde 202607. Alternativa explícita:

python -m scripts.descargar_prepagas --periodos 202607 202608 202609 202610 202611
Noviembre 2026 está incompleto: al 7/11 tenía 7.748 filas contra 11.801 de octubre, porque las entidades siguen cargando. Una comparación noviembre vs. octubre usa solo los planes presentes en ambos y puede mostrar cobertura baja. Se completa durante el mes; por eso la rutina semanal revisa los últimos dos meses.

5. Ver el resultado antes de la app

python -m scripts.consultar_prepagas --mes 202610 --base 202609

Imprime la variación por región (con cobertura, planes comparables / nuevos / perdidos), el nacional, las 10 entidades que más inciden y cuántas cápitas caen en regiones «dudosas». Revisá que el nacional sea razonable (varios % mensuales en este rubro es normal).

6. Subir a GitHub y reiniciar la app

  1. Subí los archivos mensuales y el código.
  2. En Streamlit Cloud: menú de la app → Reboot app.
git add externos/
git add .
git commit -m "Prepagas: cuadros tarifarios SSSalud"

7. Usar el tilde en la app

  1. Barra lateral: tildá «Incluir prepagas (se mide por mes)».
  2. La app carga solo los meses que necesita y avisa si falta alguno.
  3. En la tabla de divisiones, 06.4.1 aparece con su variación. Con el tilde apagado figura como «no relevado por SEPA» y no afecta nada.
  4. Para ver qué entidad empuja el número, abrí el detalle: las entidades se muestran como «productos» y se pueden excluir.

8. Plan B: bajar desde el navegador

Si el sitio rechaza al script de Python:

  1. Abrí https://cuadrostarifarios.sssalud.gob.ar en Chrome.
  2. F12 → pestaña Consola.
  3. Abrí scripts\prepagas_navegador.js, cambiá la línea const PERIODO = 202610; por el mes que querés, copiá todo, pegalo en la consola (si Chrome lo pide, escribí allow pasting y Enter) y esperá unos minutos. Se descarga AAAAMM.csv en Descargas. Repetí por cada mes.
  4. Importalo.
python -m scripts.descargar_prepagas --desde-csv C:\Users\tobia\Downloads\202610.csv

9. Corregir regiones dudosas

Los textos ambiguos («GENERAL», «Resto», «Interior», «ZONA CENTRO», «NO IDENTIFICADA») se resuelven con una regla razonable pero figuran como dudosa en consultar_prepagas. Para corregir uno, editá externos\prepagas\regiones.csv (separador ;, regiones separadas por coma):

region_texto;regiones
GENERAL;GBA,Pampeana,Noreste,Noroeste,Cuyo,Patagonia
ZONA CENTRO;Pampeana

Regiones válidas: GBA, Pampeana, Noreste, Noroeste, Cuyo, Patagonia. Después volvé a correr consultar_prepagas.
