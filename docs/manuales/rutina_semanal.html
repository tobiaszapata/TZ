1. Idea general

Solo cargás SEPA; prepagas se actualiza sola dentro del mismo comando. Una vez por semana alcanza: las entidades cargan sus cuadros durante el mes y a veces corrigen, así que el programa compara la cantidad de filas de los dos últimos meses con las del sitio y, si cambiaron, los vuelve a bajar.

Si el sitio de la Superintendencia está caído, la carga de SEPA no se bloquea: el paso de prepagas avisa y sigue.

2. La rutina en un solo comando

  1. Abrí PowerShell en la carpeta del proyecto.
  2. Corré la actualización completa (equivale al doble clic en actualizar.bat, que además guarda el registro en logs\actualizar.log).
  3. Esperá a que termine; al final sube todo a GitHub.
  4. En Streamlit Cloud: Reboot app si no ves los datos nuevos.
cd C:\Users\tobia\OneDrive\Desktop\JPM\IPC\relevamiento-precios
python -m scripts.actualizar

3. Qué hace cada paso

PasoAcción
1Descarga los días de SEPA que faltan.
2Los carga a la base.
2bPrepagas: baja meses nuevos desde 202607; para los dos últimos meses locales compara el total del sitio con tus filas y re-baja si difiere.
3Exporta el día a historico\.
4git add historico/ externos/, commit y push.
5Regenera el HTML de la app.

4. Qué mirar en el resultado

En el paso 2b el programa imprime una línea por mes revisado:

MensajeSignifica
«202611: sin cambios (N filas)»Nada nuevo; no se baja ni se sube nada.
«202611: el sitio tiene X filas y vos Y: se vuelve a bajar»Entraron o se corrigieron cuadros. Normal en las primeras semanas del mes.
«202611: N filas guardadas»Mes nuevo o re-bajado, ya guardado.
Aviso de sitio no disponible / errorNo se pudo consultar. Los datos previos quedan intactos; reintentá otro día.
Un mes nuevo recién publicado llega incompleto (el 7/11 noviembre tenía 7.748 filas vs 11.801 de octubre). Su variación puede mostrar cobertura baja hasta que las entidades terminen de cargar.

Para ver el detalle de un mes:

python -m scripts.consultar_prepagas --mes 202611 --base 202610

5. Cómo leer los números en la app

  • Para la semanal de Alimentos: dejá el tilde «Incluir prepagas» apagado. Nada cambia.
  • Para el mensual de todo lo relevado: prendé el tilde. Si ambas ventanas están en el mismo mes, prepagas da 0%; si cruzan de mes, aparece el salto de cuota.
  • Un mes sin archivo avisa «sin dato» y no rompe el cálculo.

6. Si usás correr_dia a mano

Ese flujo no incluye prepagas. Después de cargar SEPA, corré solo prepagas (con --subir hace el commit y push de externos\):

python -m scripts.actualizar_prepagas --subir

Opciones: --desde AAAAMM (piso, por defecto 202607), --hilos N (por defecto 4), --estricto (falla con error si el sitio no responde).

7. Programarlo en el Programador de tareas de Windows

  1. Abrí «Programador de tareas» → Crear tarea básica.
  2. Nombre: «Relevamiento IPC semanal». Desencadenador: Semanal, elegí día y hora (la PC debe estar prendida).
  3. Acción: Iniciar un programa → seleccioná actualizar.bat de tu carpeta.
  4. En «Iniciar en» poné la carpeta del proyecto: C:\Users\tobia\OneDrive\Desktop\JPM\IPC\relevamiento-precios.
  5. Finalizar. Probalo con clic derecho → Ejecutar y revisá logs\actualizar.log.
